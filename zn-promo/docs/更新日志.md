## [2.1.0] — 2026-07-24

- 新增 `swagger.html`：独立可离线打开的 Swagger UI 接口文档页面
- 新增 `openapi.json`：标准 OpenAPI 3.0 规范文件，可导入 Apifox/Postman
- 新增 `docs/` 目录，包含需求文档与更新日志

## [2.0.0] — 历史版本

### 新增

- 基于 FastAPI 的后端 API 服务
- JWT 身份认证（OAuth2 Password Flow）
- 合作意向在线提交与管理
- 管理员后台（admin.html）
- 前端宣传页（zn-promo.html）
- 二维码海报页（qr-poster.html）
- SQLite 数据库持久化
- 记录 CRUD、批量操作、状态管理
- 数据统计与 CSV 导出
- 操作日志记录与查询
- CORS 跨域支持
