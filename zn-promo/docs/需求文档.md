# 中南电力数智科技宣传平台 — 需求文档

**版本**: v2.1.0
**日期**: 2026-07-24
**模块**: 前端宣传页（zn-promo.html）+ 后端 API（app.py）

---

## 1. 项目概述

中南电力数智科技合作登记系统是一套基于 FastAPI + HTML 构建的企业级宣传与合作意向登记平台，面向能源电力行业展示数智化产品与解决方案，并提供合作意向在线登记与后台管理能力。

### 1.1 目标用户

| 用户角色 | 场景描述 |
|---------|---------|
| 企业访客 | 浏览公司介绍、产品矩阵、解决方案，提交合作意向 |
| 管理员 | 登录后台，查看/管理合作登记记录，导出数据，查看统计 |

### 1.2 业务范围

- 公司品牌与实力展示
- 核心支撑平台介绍
- 数智产品矩阵展示（软件产品 + 硬件装备）
- 行业解决方案展示
- 合作意向在线登记
- 后台记录管理与数据统计

### 2.4 交互需求

- **Tab 切换**：数智产品区支持「软件产品 / 硬件装备 / 行业方案」三 Tab 切换
- **滚动动画**：卡片进入视口时触发淡入上升动画（AOS）
- **表单验证**：合作登记表单实时校验姓名、手机号、邮箱格式
- **响应式布局**：适配桌面端（≥1024px）、平板（768-1024px）、移动端（<768px）
- **锚点导航**：点击导航项平滑滚动到对应区域

## 3. 后端 API 需求（app.py）

### 3.1 接口总览

| 分类 | 接口数量 | 是否需要鉴权 |
|------|---------|-------------|
| 认证 | 1 | 否 |
| 公开提交 | 1 | 否 |
| 记录管理 | 8 | 是 |
| 统计与导出 | 2 | 是 |
| 操作日志 | 1 | 是 |
| **合计** | **13** | — |

### 3.2 认证模块

| 需求编号 | 接口 | 描述 | 状态 |
|---------|------|------|------|
| REQ-A01 | `POST /token` | OAuth2 Password Flow，用户名密码获取 JWT | ✅ 已实现 |
| REQ-A02 | JWT 有效期 | 30 分钟 | ✅ 已实现 |
| REQ-A03 | 加密算法 | HS256 | ✅ 已实现 |
| REQ-A04 | 默认账号 | admin / admin123 | ✅ 已实现 |

### 3.3 合作登记模块

| 需求编号 | 接口 | 描述 | 状态 |
|---------|------|------|------|
| REQ-R01 | `POST /api/submit` | 公开提交合作意向，无需鉴权 | ✅ 已实现 |
| REQ-R02 | `GET /api/records` | 分页列表，支持搜索/方向/状态/日期筛选 | ✅ 已实现 |
| REQ-R03 | `GET /api/records/{id}` | 获取单条记录详情 | ✅ 已实现 |
| REQ-R04 | `PUT /api/records/{id}/status` | 更新单条状态 | ✅ 已实现 |
| REQ-R05 | `PUT /api/records/batch/status` | 批量更新状态 | ✅ 已实现 |
| REQ-R06 | `DELETE /api/records/{id}` | 删除单条记录 | ✅ 已实现 |
| REQ-R07 | `DELETE /api/records/batch` | 批量删除记录 | ✅ 已实现 |

**状态枚举**：`pending`（待处理）/ `contacted`（已联系）/ `cooperated`（已合作）/ `rejected`（暂不考虑）

**感兴趣方向枚举**：`core` / `powerplant` / `grid` / `newenergy` / `others` / `hardware` / `software` / `custom`

### 3.4 统计与导出模块

| 需求编号 | 接口 | 描述 | 状态 |
|---------|------|------|------|
| REQ-S01 | `GET /api/count` | 获取记录总数（可按方向/状态筛选） | ✅ 已实现 |
| REQ-S02 | `GET /api/statistics` | 获取统计总览：总数、各状态计数、方向分布、近7日趋势 | ✅ 已实现 |
| REQ-S03 | `GET /api/export` | 导出筛选结果为 CSV 文件（中文映射） | ✅ 已实现 |

### 3.5 操作日志模块

| 需求编号 | 接口 | 描述 | 状态 |
|---------|------|------|------|
| REQ-L01 | `GET /api/logs` | 操作日志列表，支持按操作类型筛选、分页 | ✅ 已实现 |
| REQ-L02 | 自动记录 | 提交/更新/批量更新/删除/批量删除/导出 均自动记录 | ✅ 已实现 |

### 3.6 数据库设计

**cooperation 表（合作登记表）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增主键 |
| name | TEXT NOT NULL | 姓名 |
| company | TEXT NOT NULL | 单位名称 |
| phone | TEXT NOT NULL | 手机号码 |
| email | TEXT | 电子邮箱 |
| interest | TEXT NOT NULL | 感兴趣方向 |
| message | TEXT | 合作意向说明 |
| status | TEXT | 状态，默认 pending |
| created_at | TEXT NOT NULL | 创建时间 |
| updated_at | TEXT NOT NULL | 更新时间 |

**operation_log 表（操作日志表）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增主键 |
| action | TEXT NOT NULL | 操作类型 |
| target_id | INTEGER | 目标记录 ID |
| target_name | TEXT | 目标名称 |
| operator | TEXT NOT NULL | 操作人 |
| ip_address | TEXT | IP 地址 |
| created_at | TEXT NOT NULL | 操作时间 |

## 4. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 首屏加载 ≤ 3s；API 响应 ≤ 500ms（1000 条数据内） |
| 兼容性 | Chrome / Edge / Safari / Firefox 主流浏览器最新两个版本 |
| 响应式 | 适配 320px - 1920px 屏幕宽度 |
| 安全性 | JWT 鉴权；密码哈希存储；CORS 配置 |
| 可维护性 | 代码结构清晰；Swagger 文档自动生成 |
